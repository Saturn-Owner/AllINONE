# Internes Code Review – Version 0.2.1

Datum: 12. Oktober 2026. Geprüft wurden Browser-App, Tresor und Sicherungen, Synchronisation/Google Drive, Chromium-Erweiterung, Server/API/SSH/KI, Offline-Cache, Build und Linux-Aktualisierung.

Dies ist eine interne Codeprüfung mit reproduzierbaren Funktionsprüfungen, kein unabhängiges Sicherheitsgutachten. Die Liste beschreibt bestätigte Fehler und konkrete Begrenzungen, die verbessert wurden; sie ist kein Nachweis, dass keine weiteren Fehler existieren.

## Nachweise

- `npm run test:all`: Typprüfung und Build, anschließend 37 Node-/Browser-/Server-Prüfungen und 9 Python-Updater-Prüfungen. **Alle 37 und alle 9 bestanden, keine Prüfung wurde übersprungen.**
- Neue Regressionsfälle umfassen verspätetes Entsperren/Wiederherstellen, fremde Änderungen während einer Verschlüsselung, Entwürfe während eines Abrufs, falsche Bearbeitungsziele in einer Warteschlange, Rücksetzen einer Koppelung in einem anderen Fenster, atomare Sicherungen, CSV-Konten und serverseitige Ablehnung defekter Hüllen.
- OpenSSH-SFTP wird gegen einen temporären lokalen SSH-Server geprüft, einschließlich Größenlimit, erlaubten und verbotenen Symlinks sowie Traversal.
- Build-Fingerprint und Cache-Aufräumen werden separat geprüft; ein Build in einer westlichen Zeitzone wurde ausgeführt.
- `npm audit` meldete für Produktions- und Entwicklungsabhängigkeiten keine bekannten Schwachstellen.
- Linux-Paket: SHA-256, Paketgröße, Entpacken, installierter Build-Fingerprint und enthaltenes Erweiterungspaket geprüft. Der echte GitHub-Abruf wurde erfolgreich geprüft: Update von 0.2.0 auf 0.2.1, Erkennung des aktuellen Stands, Reparatur einer gelöschten App-Datei und Erhaltung einer eigenen Datei.

## Grenzen

Google OAuth und Ollama-Antworten verwenden Testdienste; die Tests ersetzen keine Anmeldung an deiner späteren Google-Konfiguration oder einen Live-Test deines Modells/VPS. Die Cloud-Browserrichtlinie verbietet das Installieren eigener Chromium-Erweiterungen; getestet werden das tatsächlich ausgelieferte Popup und Ausfüllskript mit einer adaptierten Chrome-API. Die Installation ist zusätzlich auf deinem Rechner zu prüfen.

Die Verschlüsselungsverfahren und Passphrase bleiben unverändert. Das Review ist keine Garantie für Fehlerfreiheit, „Unknackbarkeit“ oder Sicherheit eines kompromittierten Geräts beziehungsweise einer manipulierten Auslieferung. Details stehen in [SECURITY.md](SECURITY.md).
